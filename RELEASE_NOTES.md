# Release notes

## Documentation and reproducibility materials

- Provides separate computational materials for the SSAQS global SHAP, RELAX global SHAP and RELAX participant-level local-stability analyses.
- Includes analysis scripts and notebooks, software-version information, aggregate and fold-level results, figures, and numerical comparison results.
- Excludes observation-level predictions and SHAP exports, participant-coded local-stability records and participant-level SHAP arrays to reduce disclosure risk.
- Does not redistribute the original source datasets or the RELAX questionnaire workbook.
- No software DOI is assigned. Repository citation metadata should be updated only after a versioned public release has been archived and a DOI has been verified.
