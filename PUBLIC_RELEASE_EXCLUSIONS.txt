# Data Availability, Privacy and Excluded Materials

This repository does not redistribute source datasets or generated files that contain observation-level or participant-linked information. The exclusions below identify data products that are not included in the public research materials.

## RELAX analysis table and participant-level outputs

- `RELAX_next_morning_stress_dataset.csv` (including copies in subdirectories): reconstructed modelling table containing participant-linked records, timestamps, outcomes and predictors.
- `RELAX_Participant_Level/outputs/`: generated participant-level analysis outputs.
- `RELAX_local_SHAP_observation_stability_pseudonymised.csv`: observation-level stability records.
- `RELAX_local_SHAP_participant_stability_pseudonymised.csv`: participant-coded stability records.
- `RELAX_local_SHAP_values.npy`: observation-level SHAP attribution array.
- `RELAX_local_SHAP_fold_allocation_summary.csv`: fold-allocation records.
- `RELAX_local_SHAP_run_metadata.json`: metadata associated with the generated participant-level outputs.

## RELAX global analysis outputs

- `RELAX_global_SHAP_heldout_values.csv`: held-out observation-level predictions and SHAP values.
- `RELAX_global_SHAP_fold_audit.csv`: fold-level diagnostic records.
- `RELAX_global_SHAP_integrity_checks.csv`: run-specific numerical and structural check results.
- `RELAX_Global_SHAP_Controlled_Notebook_Run/`: local analysis workspace containing extracted input data and generated outputs.

## SSAQS global analysis outputs

- `SSAQS_prediction_comparison.csv`: observation-level prediction comparisons.
- `SSAQS_global_SHAP_heldout_values.csv`: held-out observation-level SHAP values.
- `SSAQS_global_SHAP_oof_predictions.csv`: observation-level out-of-fold predictions.
- `SSAQS_Global_SHAP_Analysis/`: local analysis workspace containing extracted source data and generated outputs.
- `SSAQS_Global_SHAP_outputs.zip`: archive of generated SSAQS outputs that may contain restricted records.

## Privacy considerations

The RELAX participant-level pseudonymised exports remain linked to observations and participants. Row indices, timestamps and combinations of attributes may permit linkage; pseudonymisation does not, by itself, establish anonymisation. The SSAQS prediction-comparison and held-out exports contain participant- and time-linked predictions or SHAP information. The RELAX global held-out export contains participant-linked predictions and SHAP values.

The reviewed `RELAX_global_SHAP_run_metadata.json` is retained as aggregate computational metadata. It records the input checksum, dataset dimensions, participant count, model configuration, software versions and aggregate numerical comparisons, without participant identifiers, row-level records, timestamps or local filesystem paths. Other generated metadata should be assessed individually before any further distribution.

Notebook outputs have been cleared while executable source cells have been retained. Running the notebooks and scripts may regenerate some of the excluded files. The public repository therefore contains analysis procedures and aggregate findings, but not all intermediate data products.

These exclusions reduce the risk of disclosing participant-linked information. They do not establish that all possible disclosure risks have been eliminated.
